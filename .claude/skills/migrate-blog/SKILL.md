## name: migrate-blog description: Migrate blog posts — download images, create markdown with frontmatter, fix paths

# Blog Migration Skill

$ARGUMENTS

1. Download all images from the source URL to images/ directory
1. Create markdown post with proper frontmatter (title, date, tags)
1. Fix image paths to use relative ../images/ prefix
1. Convert any platform-specific formatting to standard markdown
1. Keep the post as a single file, minimal and clean
