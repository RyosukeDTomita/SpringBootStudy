# Blog Migration Skill

$ARGUMENTS

1. Download all images from the source URL to images/ directory
2. Create markdown post with proper frontmatter (title, date, tags)
3. Fix image paths to use relative ../images/ prefix
4. Convert any platform-specific formatting to standard markdown
5. Keep the post as a single file, minimal and clean
